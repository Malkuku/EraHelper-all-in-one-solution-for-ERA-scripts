# MVU 核心版本目录

此目录保存维护者手动发布的核心版本文件，版本目录（例如 `2.0.0/`）一旦发布不得覆盖。

当前尚无正式版本文件或 `latest.json`。请勿将示例提交号或候选文件冒充正式公告。

使用仓库根目录的 `pnpm release:stage` 准备版本目录。审阅、提交并推送产物后，运行 `pnpm release:announce --version 版本 --commit 产物的完整提交号`，核对 CDN 实际字节后才生成本地公告；再审阅、提交并推送公告。

完整步骤与首次安装见 [发布指南](../../Spec/Me2AI/MVU发布准备指南.md)。
