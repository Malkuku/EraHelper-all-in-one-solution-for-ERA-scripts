# 核心项目说明

## 项目定位

根据当前 README 与代码，MVU 助手是运行在 SillyTavern 酒馆助手环境中的脚本，帮助用户配置分步模型任务、编辑 MVU 的 `stat_data`，并根据世界书中的版本规则更新变量。构建产物由 `src/MVU助手/index.ts` 进入，界面在脚本运行时挂载。

## 当前可见场景

- 从脚本按钮打开配置界面，管理分步任务组、任务池、模型配置和结果合并方式。
- 在消息事件或自定义事件后执行任务，将生成内容写入消息或世界书，并按 MVU 接口更新变量。
- 编辑当前消息的 `stat_data`，或预览并执行世界书定义的版本更新。

## 边界与状态

EraDataRule/DSL 规则引擎已被移除，不属于现行产品能力。仓库中的规则指南、示例、测试数据和旧流程图仅是历史资料；版本更新所用的世界书更新块是独立的现行机制。
