# 分步分析契约

状态：2026-10-17 已由独立任务机制替代旧实现；本地确定性行为验收已覆盖生成、调度、提交与配置，实际宿主集成仍待验收。详细 schema、事件与支持矩阵唯一权威见 [分步任务契约](./分步任务目标契约.md)，本文只提供入口和责任导航。

## 配置与入口

`stores/TaskStore.ts` 保存脚本变量 `async_task_config`，任务、组、连接、插件预设均通过稳定 ID 引用。正则库 `regexPresets` 缺省为空，编辑时复制复用，不另建运行规则源。连接密钥单独放在同源浏览器本地存储，普通配置仅保留引用。配置保存只检查结构，允许空连接/模型/绑定及未完成预设；删除引用中的资源清空使用方引用并保留使用方。删除共享权威与相关任务运行前完备性验证位于 `TaskConfiguration.ts`，运行前失败不会发请求，闲置未完成资源不阻止正常任务；具体规则见详细契约。旧模块配置明确拒绝执行并提示重新配置；加载时仅清理旧模块连接明文，用户保存新配置后删除旧运行配置键，不迁移旧任务或密钥。用户正则库 `saved_regex_configs` 保留并可显式导入，不属于旧运行配置删除范围。

新界面由 `TaskManager.vue` 编辑，`UI/view/AsyncAnalyze.vue` 显示在途运行、取消按钮、逐任务结果与纯返回文本。按钮重算、消息事件、自定义事件和 `KatTaskAPI.run` 都进入 `TaskRuntime.runTaskChain`，不再存在旧生成入口、Profile、全局预设切换或正文世界书过滤路径。

## 调度与生成

`MESSAGE_SENT` 的负 order 链 await 自己完成后正文继续；`MESSAGE_RECEIVED` 的非负 order 链是另一个独立运行。同 order 并发，组间有序。任务的附加事件名增加显式触发入口，不使它退出常规链；enabled 只控制常规链参与，事件忽略该开关。

enabled 仅控制常规链参与，关闭后仍可由匹配事件触发。触发间隔恢复原版：基线缺省0，仅间隔>1检查楼层差，包含事件；楼层回退时跳过并重置间隔基线。显式 taskId 单任务测试绕过间隔。

常规链的 busy 与事件 busy 使用不同判别键；同一聊天的常规链不重入，同一脚本/聊天/事件名不重入，不排队。不同事件及事件与常规链可并发。切聊天只取消所属旧聊天运行，并在每个后续写入前校验聊天、消息原始对象及 swipe 身份。

任务复制预设、候选条目、历史与扫描状态，消费 `generation/` 的原生扫描移植、任务预设组装、宏/EJS adapter，最后独立 fetch 原版同源 Chat Completions 后端。任务不调用酒馆助手完整 generate，也不广播全局生成事件。

## 输出与恢复

任务显式选择纯返回、事件结果广播或写入。广播支持所有触发方式，事件执行沿事件名:result、常规与无事件单任务沿kat_task_chain:result交付一次完整终态和tasks[].text，不持久保存结果；任务结果处理可复制当前任务的前端联动提示词，运行页提供事件和单任务真实测试。写入基于最新消息/条目内容重新匹配，正文 MVU 先纯解析，真正持久化成功后才报告任务成功。事件各任务独立结算；常规链失败撤销本次已提交操作。替换条件失效不降级追加。

`TaskCommit.ts` 是消息片段、世界书 UID 与 MVU JSON 路径所有权的权威责任层，短锁覆盖目标事务，不覆盖模型网络等待。同一消息的独立片段、MVU 稳定数组不同索引可独立撤销；祖孙路径、数组结构与重叠片段警告继续，无法证明归属时返回回滚冲突，不写回整份旧快照。

`TaskState.ts` 将成功历史和 sticky/cooldown 状态放在聊天变量，按 task 隔离，迟到结算与重载后的同楼运行通过持久化高水位和 tombstone 合并。运行 Journal 与最后可重算链只存在于当前脚本会话内存，未承诺跨重载恢复。专用重算发现该楼有成功历史但缺少可用 Journal 时返回回滚不可用失败，既不恢复旧正文也不再次生成。

补偿失败会在统一结果中保留失败，并在 `KatTaskAPI.getUnrecoveredJournals()` 暴露当前会话剩余操作的只读快照；不提供自动重试写入或持久恢复机制。结果发布后是独立终态快照，后续重算不改旧调用方结果。
