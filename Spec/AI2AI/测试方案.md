# 测试方案

## 当前验证入口

- `pnpm build:dev` 与 `pnpm build`：Webpack 编译脚本。`pnpm lint`：静态检查。仓库目前没有 `test` 脚本。
- `src/MVU助手/doc/单元测试用/` 保存已移除 EraDataRule 机制的历史样例；当前没有对应引擎或自动执行入口，不属于现行测试资产。
- 宿主 API 依赖 SillyTavern、酒馆助手和 MVU 运行环境；构建成功不能证明消息、世界书或变量行为正确。

## 独立任务测试权威入口

稳定资产唯一根为 `tests/async-tasks/`。实现自测与独立验收补缺使用同一入口，不维护平行 acceptance 副本。

自定义常驻通知回归继续使用 runtime（开始/终态按 runId 替换、并发/忙碌/自动静默、部分失败/取消/回滚及通知异常隔离）；generation --errors-only 同时核验界面保留日志的请求/响应和密钥脱敏。上述 diagnostics.cjs 增补真实运行入口的顶层通知、失败日志/复制、主窗口关闭后等待超过旧 toast 时限、成功原位替换、手动关闭、原始输出文本转义及375宽度；`field-help-worldbook.cjs`核验提示进入顶层浮层及跨 iframe 的1200/550/375定位。新增截图 notification-running-mobile.png、notification-success-mobile.png 保留环境证据；这些模拟宿主结果不代表真实酒馆验收。

通知收起行为继续由 diagnostics.cjs 验证：默认一行、顶部居中、等待中及结束后保持收起、点击/Enter展开详情、日志阅读及再次收起；成功3秒自动消失、展开/鼠标/焦点交互暂停及失败保留。375宽度下收起高度小于80像素是本 fixture 的遮挡回归断言，不是生产截断阈值。

## 按改动选择验证

| 改动 | 最小充分验证 |
| --- | --- |
| UI 文案或布局 | 定向静态检查；可用宿主时查看对应页面。 |
| 配置格式和持久化 | 新 schema 验证保存/重载与密钥引用；旧格式验证明确拒绝和重新配置，清理仅覆盖本模块。无关模块数据与用户内容保持原样。 |
| 分步分析流程 | 在宿主中验证消息发送/接收、自定义事件、同序任务、失败重试、结果合并及回滚的受影响路径。 |
| MVU 数据编辑 | 使用有代表性的 `stat_data` 验证绑定目标写入、失败路径及消息变量一致性。 |

## 当前缺口

独立生成重构的计划验收见 [迭代任务](./迭代任务/2026-10-16-独立生成与并发任务重构.md)。该任务允许破坏性更新，旧配置用例验证明确拒绝与重新配置，不要求自动迁移。当前确定性缺口与宿主门禁分别登记于 [独立验收记录](./迭代任务/2026-10-16-独立生成验收记录.md)。

实际宿主集成测试仍缺：主聊天同时运行、部署版本与后端鉴权/协议、真实宏/EJS、预设导出回原版导入及 MVU 持久化。以后修改用户可见行为时，优先复用权威入口补原始失败案例，不用构建或 lint 代替行为验证。

`generation.cjs` 同时覆盖正文输入的可选宿主正则：默认关闭、配置往返、原文/来源/prompt/完整聊天深度传参、自定义 history 正则后置、扫描/实际请求复用、零历史不调用、不修改世界书/提示词/响应/原消息及宿主异常阻断 HTTP。格式化接口使用 mock，此证据不替代真实酒馆全局/预设/局部正则启停及深度组合验收。

`generation.cjs` 同时覆盖助手内置变量宏：原始输入 `{{get_message_variable::stat_data.世界.时间}}`、最后带变量楼层选择、五作用域的 get/format/quoted、字符串/数字/缺失/嵌套私有字段、缩进、与原生宏混用、实际请求的任务/预设/世界书展开及扫描关键词、EJS 输出宏和变量读取失败零发送。宿主 getVariables 使用 mock，真实酒馆宏与变量集成仍需现场确认。
