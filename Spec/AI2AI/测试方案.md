# 测试方案

## 当前验证入口

- `pnpm build:dev` 与 `pnpm build`：Webpack 编译脚本。`pnpm lint`：静态检查。仓库目前没有 `test` 脚本。
- `src/MVU助手/doc/单元测试用/` 保存已移除 EraDataRule 机制的历史样例；当前没有对应引擎或自动执行入口，不属于现行测试资产。
- 宿主 API 依赖 SillyTavern、酒馆助手和 MVU 运行环境；构建成功不能证明消息、世界书或变量行为正确。

## 独立任务测试权威入口

稳定资产唯一根为 `tests/async-tasks/`。实现自测与独立验收补缺使用同一入口，不维护平行 acceptance 副本。

| Test | Layer | Role | Mode | Responsibility |
| --- | --- | --- | --- | --- |
| [generation.cjs](../../tests/async-tasks/generation.cjs) | component / contract | primary | deterministic | 生成上下文与并发载荷隔离、原生扫描及时序边界、预设字段保留、分区/深度角色顺序、模板 adapter/特殊条目阶段、取消迟到及预算拒发。 |
| [commit.cjs](../../tests/async-tasks/commit.cjs) | component / contract | primary | deterministic | 最新目标提交、提取/替换、片段与 MVU 路径所有权、创建条目身份、补偿失败、时序状态合并/撤销。 |
| [runtime.cjs](../../tests/async-tasks/runtime.cjs) | component / contract | primary | deterministic | busy/关联与并发准入、启停/阈值/间隔/分链、逐任务终态、重试取消、事件部分成功、常规链回滚、聊天切换及重载恢复边界。 |
| [configuration.cjs](../../tests/async-tasks/configuration.cjs) | component / contract | primary | deterministic | 唯一配置 schema、旧格式拒绝与清理边界、持久化重载、配置/密钥引用隔离、脚本秘密命名空间与损坏错误；正则库缺省兼容、保存重载、旧库保留与显式格式导入、匹配预览语义。 |

2026-10-17：四个入口均完成独立补缺与受影响验证，所列确定性场景通过；原始失败反例保留为回归保护。四个入口均保留为长期主要责任测试，不另留 acceptance/regression 副本。实际宿主、真实 EJS 引擎和原生预设 UI 导入导出仍未验收，整体验收保持待宿主验证；具体证据与剩余范围见验收记录。

依赖已恢复，确定性验证命令：

```powershell
node tests/async-tasks/generation.cjs
node tests/async-tasks/commit.cjs
node tests/async-tasks/runtime.cjs
node tests/async-tasks/configuration.cjs
```

仅生成错误处理发生变化时，可运行同一入口的 `node tests/async-tasks/generation.cjs --errors-only`，覆盖通用异常阶段、明确错误保留和取消迟到拒绝；默认命令也包含这些场景。

场景与缺口见 [独立验收记录](./迭代任务/2026-10-16-独立生成验收记录.md)。

任务配置 UI 恢复的浏览器交互验收与临时脚本证据见 [恢复任务配置界面与操作能力](./迭代任务/2026-10-17-恢复任务配置界面与操作能力.md)。浏览器中实际挂载生产 Vue 组件，世界书接口使用模拟宿主；覆盖选择、失败重试、迟到响应、正则复用和草稿，不等同于实际酒馆集成验收。临时 webpack/Playwright 脚手架只作为本次验收证据，不建立第二套稳定测试根。

## 按改动选择验证

| 改动 | 最小充分验证 |
| --- | --- |
| UI 文案或布局 | 定向静态检查；可用宿主时查看对应页面。 |
| 配置格式和持久化 | 新 schema 验证保存/重载与密钥引用；旧格式验证明确拒绝和重新配置，清理仅覆盖本模块。无关模块数据与用户内容保持原样。 |
| 分步分析流程 | 在宿主中验证消息发送/接收、自定义事件、同序任务、失败重试、结果合并及回滚的受影响路径。 |
| MVU 数据与版本更新 | 使用有代表性的 `stat_data` 和世界书版本块验证预览、写入、失败路径及消息变量一致性。 |

## 当前缺口

独立生成重构的计划验收见 [迭代任务](./迭代任务/2026-10-16-独立生成与并发任务重构.md)。该任务允许破坏性更新，旧配置用例验证明确拒绝与重新配置，不要求自动迁移。当前确定性缺口与宿主门禁分别登记于 [独立验收记录](./迭代任务/2026-10-16-独立生成验收记录.md)。

实际宿主集成测试仍缺：主聊天同时运行、部署版本与后端鉴权/协议、真实宏/EJS、预设导出回原版导入及 MVU 持久化。以后修改用户可见行为时，优先复用权威入口补原始失败案例，不用构建或 lint 代替行为验证。
