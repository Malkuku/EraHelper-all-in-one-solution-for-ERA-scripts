# 事件触发修复与前端结果联动

状态：本地实现、独立验收与生产构建完成；真实宿主待验收。

## 目标与决定

- 恢复原版语义（c45e3890 Service 与 TaskEditorModal 为证据）：enabled 仅控制常规链；事件匹配忽略 enabled。关闭常规参与即可使任务仅事件运行，开启则可参与两种入口。
- 恢复原版楼层间隔：未触发以0为基线，仅间隔>1检查，包含事件；楼层差达到间隔才执行。历史高于当前楼层时本次跳过并重置间隔基线，不能写成成功历史。
- 运行页可按已保存配置测试常规链、某个事件或单个任务。测试是真实执行，展示写入影响并检查依赖；单任务显式执行绕过楼层间隔，事件整体测试遵守间隔。事件单测保留事件语义和结果频道。
- 新增 output.mode=event_result，完整响应通过既有事件名:result的tasks[].text广播，含事件名、请求、运行、聊天、楼层与任务归属；不持久化结果，不写正文/世界书/MVU。只允许实际事件执行使用，常规误配在prepare失败。
- 支持请求对象 { requestId?, messageId?, taskId? }，保留字符串 requestId 调用。提供可复制联动规则，包括等初始化、先监听后触发、关联结果与广播消费。

## 分工与测试所有权

- 内核实现 Agent：调度、事件请求、schema、结果广播与间隔状态，以及必要实现自测。
- 父 Agent：UI、联动说明、长期 Spec 与集成审阅。
- 提示恢复 Agent：恢复配置字段 hover 说明，同时支持焦点与点击；内容以恢复后的规则及现有能力为准。
- 独立测试 Agent：从上述规则推导原始失败案例、生产事件监听入口、结果广播与失败反馈、配置和浏览器交互验收；复用 tests/async-tasks 权威入口。

## 验收与验证范围

- 关闭常规参与的事件任务可由事件执行；开启常规参与可执行常规与事件；无事件名且关闭才跳过。
- 间隔首次0起算、间隔1重复执行、事件间隔与回退楼层基线重置有回归。
- 单任务测试仅执行指定任务，覆盖负 order、事件任务、未关联/错误任务 ID，明确失败原因。
- 实际注册事件可接收字符串和请求对象，requestId 和楼层传递正确；busy、错误、部分成功均有对应 result。
- 其它前端先监听后触发，按requestId和taskId处理广播；并发、busy、partial、失败均有准确终态。结果不持久化且不建立重复频道。
- 运行 UI 提供事件/任务选择、写入提示和可复制规则；生产构建与定向 ESLint。
- 真酒馆与真实模型无法在模拟环境证明，单独记录宿主缺口。
