## 测试发现与所有权

- 稳定既有入口：`tests/async-tasks/{generation,commit,runtime,configuration}.cjs`，配置/任务契约复用这些入口。
- 历史浏览器入口位于系统临时目录 `kat-ui-review-20261017` 和 `kat-ui-acceptance`，只挂载 Layout 与 TaskManager；不能作为完整 App 路由验收证据。
- 本轮浏览器 fixture 将挂载生产 `UI/App.vue`、生产 router 与实际页面/store，仅模拟宿主 API，不替换页面或业务状态实现。
- 新变量/版本确定性验证由稳定责任建立单一主要入口；浏览器脚手架作为本轮验收证据，命令与关键结果在此归档。
- 实际酒馆父页样式、真实模型/MVU持久化、软键盘及主题集成没有可用宿主，不以模拟结果替代。

## 执行结果

### 确定性行为与相邻回归

以下命令均通过；原始失败反例保留在唯一稳定责任入口中：

```powershell
node tests/mvu-editing.cjs
node tests/async-tasks/generation.cjs
node tests/async-tasks/commit.cjs
node tests/async-tasks/runtime.cjs
node tests/async-tasks/configuration.cjs
```

`mvu-editing.cjs` 是新建立的手工变量/版本能力主要测试，已按测试治理读取已有索引与目录后建立，并登记测试方案；不复制到 acceptance 目录。覆盖追加楼层、切聊天、切 swipe、消息对象替换和同数据基线变化；异步初始化/来源读取后的再次阻断；精确楼层及未改字段保留；1.04→1.05、逐路径旧新差异、坏 JSON/无效版本/非对象/未闭合块/无块；setter 失败保留预览；来源变化阻断；两份手工草稿并发只允许第一份基线提交；真实 TaskCommit 与手工提交双向串行；通知监听器嵌套保存不会死锁，后续变更明确返回完成确认歧义。

锁职责抽取后重跑了受影响的 commit/runtime 及此新入口；configuration/generation 验证原配置、正则、API绑定、生成边界继续有效。未通过大量重复测试制造独立性。
