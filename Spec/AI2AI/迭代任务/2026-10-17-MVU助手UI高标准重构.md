# MVU 助手 UI 高标准重构

- 状态：本地实现、独立验收与生产构建完成，待真实酒馆宿主验收。
- 授权：用户明确要求“报告后直接实施 UI 重构并验证”。
- 依据：[综合问题报告](../调研/2026-10-17-MVU助手UI问题报告与重构要求.md)及两个角色报告。
- 目标与范围：修复报告U01–U15，重构完整窗口、任务配置工作台、草稿/保存、运行结果、变量与更新交互；保留独立任务内核及现有产品能力。
- 设计：顶栏与导航进入布局流，按实际可用空间响应；生效与草稿状态分开；整体配置仍一次保存，明确全局范围；保留非秘密草稿与会话内编辑上下文，密钥不新增持久化渠道；变量与版本预览绑定聊天/楼层/swipe及基线，变化阻断并保留草稿；对话框共享键盘与焦点生命周期。
- Agent分工：designer_review 承担窗口/导航/TaskManager与共享视觉系统主要实现及最小自测；player_review 承担变量/版本更新及目标安全主要实现和最小自测；root负责共享弹窗、运行结果、协调与Spec；独立验收Agent负责从本任务推导风险矩阵及正式验收，不由实现角色代替。
- 文件所有权：designer拥有Layout、TaskManager、全局样式与App；player拥有EraDataEditor、EraEditStore、VersionUpdater、UseVersionControlStore、新数据目标校验；root拥有AsyncAnalyze、对话框与相关utils。共享文件变更先沟通。
- 验收：U01–U15逐项映射；全局保存范围与字段定位清晰；旧raw导出、失败退出预览、版本精度、草稿丢失反例修复；运行首层呈现数据影响；1024×600/768×600不裁切，375×812无溢出；键盘弹窗可闭环；原世界书/正则/API交互回归通过。
- 验证范围：实际完整SFC模拟宿主浏览器、目标身份/基线/导出/更新失败定向行为验证、受影响既有配置与任务suite、定向lint及生产构建；真实酒馆/模型/MVU缺失环境单列门禁。
- 测试所有权：实现各自最小自测；独立验收Agent拥有正式验证结论；复用tests/async-tasks与已有临时浏览器入口，数据安全若无稳定归属按测试治理建立单一主要入口。
- 旧职责取缔：旧固定小窗口与重复导航布局、各入口独立的弹窗焦点处理、变量/版本提交时重新定位最后楼层、静默跳过损坏版本块、失败后退出预览由新路径替代；不移除独立任务能力或用户数据。
- 同目标并发责任收敛：将原TaskCommit中的通用锁原样移入中立`utils/TargetLocks.ts`，TaskCommit/TaskState与手动编辑直接消费，无旧wrapper/reexport；仅改变锁归属和新增手动入口串行，不改任务业务语义。
- 文档：更新架构UI约束、MVU数据契约、测试索引/方案、配置指南、任务与索引；审阅报告保留为实施前快照并链接完成记录。

### 验证与边界

- 独立验收由`ui_acceptance`先建立风险矩阵，再编译生产App+router+实际页面/store，仅模拟宿主API；详见 [独立验收记录](./2026-10-17-MVU助手UI独立验收记录.md)。实现自测与正式验收分别记录。
- 正式验收覆盖24组路由/尺寸组合，包含原600px高裁切反例；200%使用等效CSS可用空间检查，未冒充实际宿主zoom或软键盘验收。
- 原有4个`tests/async-tasks/` suites及新增唯一主要入口`tests/mvu-editing.cjs`由独立Agent验证；新增入口覆盖目标漂移、基线、版本规则、失败保留、同目标并发与通知重入。
- 最后键盘补验通过：数字与布尔树形节点可由键盘展开、编辑、Esc仅取消节点并恢复焦点，应用进入同一草稿；最终bubble事件版嵌套弹窗仍通过Tab/Esc/背景inert与滚动恢复。共享弹窗样式收敛为`Dialog/dialog.scss`，不再复制主题token。
- root最终`pnpm build` exit 0，Webpack编译3225ms，产物`dist/MVU助手/index.js`约341KiB；保留包体积/入口大小三项提示与Browserslist数据库时效提示。root拥有文件定向ESLint零错误；实现角色其余改动文件定向检查通过。全仓库`tsc --noEmit`仍exit 2（既有诊断），本轮改动MVU文件无相关诊断，不宣称全仓类型检查通过。
- root审阅独立验收交付物并目视完整App桌面与手机截图，未重复仍有效正式测试。关键截图、尺寸和对比度数据及可重放fixture已随验收记录归档为证据；新增稳定测试只有`tests/mvu-editing.cjs`，未建立平行验收suite。
- 真实酒馆父页主题、实际MVU持久化/宿主setter时机、真实模型、手机软键盘和实际浏览器zoom仍为宿主门禁，不以模拟验证替代。复杂嵌套错误定位到分区、未知原生预设结构问题定位到预设；对比度为代表性抽样，未声称全站认证。
- 玩家报告、产品设计报告与综合问题报告作为实施前快照保留，最终结论以此任务及独立验收记录为准。未发布、未提交Git、未归档。

### 用户截图回归补修：导航排序与规则组布局

- 用户要求预设管理和API配置前置，并指出一个五任务组撑高同排空组的截图。归类为局部UI细节修复，由root直接实施与定向验证，不重新组织多Agent迭代。
- 标签前两项改为“预设管理”“API配置”。活动组选择从等高网格替换为纵向紧凑列表，默认只显示名称/数量/备注（如有）/状态/操作；每组任务及连接按需展开。选择、编辑、复制和顺序操作保留，选择仍在保存后生效。移除已无消费的旧active-card样式。

- 定向ESLint与生产构建通过；本次构建7383ms、约346KiB，仍有原包体积与Browserslist提示。架构与玩家指南已同步。截图、脚本与测量见 [补修验证记录](./2026-10-17-MVU助手UI独立验收记录.md#用户截图回归补修root定向验证)。
