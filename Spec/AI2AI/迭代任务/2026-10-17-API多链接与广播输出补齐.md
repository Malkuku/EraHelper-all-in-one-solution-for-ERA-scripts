# API 多链接与广播输出补齐

> 历史记录：本轮广播独立模式及实例身份插值提示词属于后续用户指出的实现偏差，已由[广播作为处理后写入目标](./2026-10-17-广播作为处理后写入目标.md)取代；API多链接结论保留。

状态：本地实现与验证完成，待真实宿主验收。

## 目标与设计

- API 配置绑定预设；内部 links 保存 id、name、baseUrl、model、secretRef，以 activeLinkId 选择当前链接。任务继续只选择 API，切换链接保存后生效；不增加自动轮换、优先级或回退。
- 配置版本升至 3。独立任务版本 1/2 在输入边界转换到单链接结构，保留 API、预设组合和密钥引用。版本 3 是唯一内部表示。
- 事件广播允许常规、手动和事件执行。事件结果继续发 `${eventName}:result`，其他执行继续发 `kat_task_chain:result`，每次运行一次终态，不新增第二次广播或持久化结果。
- 前端联动提示词从运行页移至任务结果处理；用户提供的故事预设转换提示词原文提供于预设管理，支持预览及复制，不自动修改用户预设。

## 分工与测试所有权

- API 实现 Agent：配置模型、输入升级、密钥生命周期、生成与 API 编辑闭环，最小实现自测。
- 主 Agent：广播输出与两类提示词入口、Spec 收口，负责既有 suites 与生产 UI 的集成验证；不声称独立验收。

## 验收与验证范围

- 同一 API 保存多链接，切换后请求使用所选地址、模型及密钥；未选/丢失链接只阻止相关任务，删除链接不删除任务，非活动链接密钥也保留。
- v1/v2 配置升级与保存重载、导出无密钥、运行快照保持隔离。
- 常规触发 event_result 成功返回并只广播一次，事件频道不变，失败仍可观察。
- 在结果处理复制当前任务联动提示词，在无预设时也可复制完整转换提示词；剪贴板失败明确显示。
- 复用 configuration/generation/runtime suites，生产 Vue 模拟宿主验证，定向 lint 与生产构建；真实酒馆为待现场确认。

## 旧机制取缔

- API 顶层地址、模型、密钥引用退出内部模型，由当前链接承担；旧字段仅在明确版本输入升级边界读取。
- 移除 event_result 限事件执行的阻断及过时 UI/文档说明。
- 运行页原联动提示词入口移除，任务结果处理接管。
