# 迭代任务：独立生成与并发任务重构

- 状态：待宿主验收（P1–P4 实现与确定性独立验收完成；开发/生产构建通过，真实宿主门禁未执行）
- 日期：2026-10-16
- 类型：替代既有生成与调度机制，允许破坏性更新
- 当前交付范围：用户已要求按规划执行 G0–P5；G0 门禁通过后启动业务实现，宿主验收证据不足时保持待验收状态

## 目标与范围

让每个分步任务以自己的酒馆预设副本、世界书候选池和扫描上下文独立组装请求，同组任务、不同事件及事件与主聊天可以并行生成。尽量复用原版酒馆的数据读取、宏、EJS 渲染和请求转发能力。

以清晰的权威数据模型替代全局预设切换、共享任务黑名单和完整生成锁；同时完成预设管理、事件结果、运行隔离、并发提交和回滚的业务闭环。

用户明确允许不兼容旧版本，以代码干净性为基准。旧模块配置、API 与内部结构可直接替换，不要求旧版自动迁移，不为保留旧字段和旧调用方制造兼容层。该授权不扩大为重写无关 MVU 编辑器、版本升级模块或清空用户内容。

## 关键设计决定与权威责任层

### 生成与发送

- TaskRun 上下文持有本次配置快照、预设副本、候选条目、历史、生成结果、运行标识和取消控制器；名称可在 G0 调整，职责不可重新分裂。
- 世界书扫描器只接收任务数据，按酒馆规则处理递归、概率、分组、预算、排序、位置和时序效果。摘取条目在任务副本内强制启用后正常触发，不能保证入选，也不能只做简单关键词匹配。
- 预设组装器消费酒馆原生预设副本，处理占位、排序和深度注入；排除自动角色卡提示词，保留宏和模板主动读取能力。
- 宏尽量调用宿主能力；EJS 调用 ST-Prompt-Template 的渲染能力，由任务组织预处理与生成前后阶段。getpreset 等读取适配任务预设副本；自动特殊条目仅来自候选池，显式 getwi 可读池外。
- 插件自行 fetch 原版酒馆同源 Chat Completions 后端。请求载荷显式来自本次连接与预设，不调用主聊天 Generate 或酒馆助手完整生成链，不广播全局生成事件来模拟调用。
- 不改动、分发宿主补丁，不依靠发送前事件、固定延迟或主聊天忙闲状态保证任务正确性。基于本轮实际验证的宿主能力声明支持版本，不增加旧宿主 fallback。

### 配置、预设与界面

- 只保留显式连接信息和插件预设引用的权威配置关系，删除 Profile、跟随当前连接/预设的旧模式及重复生成参数来源。
- 插件预设长期保存导入副本，按酒馆原生规则导入导出；酒馆原预设修改不会自动同步。重新导入同名副本有覆盖提示，需要保留的可另存。
- 轻量编辑器支持温度、最大 Token 等常见参数，以及提示词内容、启停和排序。高级结构可在酒馆编辑后重新导入；保留未知字段，不代表自动执行未知扩展行为。
- 新模块配置可以使用新 schema；旧格式明确提示重新配置，不自动迁移或伪装为新配置。预设文件格式兼容必须独立验收。
- 密钥本地持久化；普通配置只存引用，不继续写入脚本变量，不通过导出或日志泄漏。旧明文的清理仅限本模块。

### 调度、结果与提交

- 按 [目标契约](../API/分步任务目标契约.md) 分离常规链与事件的运行状态、取消、备份和结算。
- 生成任务不共享完整生成锁；允许针对正文/世界书写入目标的短事务锁，不能让锁覆盖网络等待。
- 事件 busy、逐任务状态、纯结果返回和写入失败均进入同一结果模型；不再另建一个只供旧事件消费的降级结果表示。
- 新版本不提供“正文配置”或正文专用过滤。旧规则组的正文 world_book 配置及相关 UI、钩子和状态全部退出，规则组仅保留任务组织职责；候选池仅属于任务，不拆出新正文过滤模块延续旧机制。

## 验收标准与最小充分验证

| 编号 | 场景 | 必须证明的结果 |
| --- | --- | --- |
| A1 | 两任务不同预设、候选池、连接与任务提示词，并与主聊天同时运行 | 请求可重叠；各载荷只含自己的生成数据；主聊天预设、候选池与取消状态不被任务切换 |
| A2 | 主聊天延迟、提前失败或取消；另一任务失败或被取消 | 无关任务继续；不因主聊天缺少完成事件持续 busy；取消只影响所属运行 |
| A3 | 候选条目原本禁用、关键词不匹配、常驻、递归、概率、分组、预算、深度和时序效果 | 强制启用后正常扫描；不匹配条目仍不发送；规则与支持矩阵一致；原条目不被改写 |
| A4 | EJS 预处理、GENERATE 前后条目、注入、池外 getwi、getpreset | 自动处理范围不越池；池外显式读取可用；读取任务预设副本；不借广播全局生成事件实现 |
| A5 | 原生预设导入→轻量编辑→导出→重新导入；同名覆盖 | 在酒馆原生格式下可往返；顺序/角色/深度等有效语义保存；未知字段保留；编辑参数为请求权威值 |
| A6 | 同名事件重复、不同事件、事件与常规链并发、MESSAGE_SENT 负 order | busy 明确可关联；无无关运行互相作废；负 order 完成后正文继续且无锁重入死锁 |
| A7 | 返回型、正文写入、世界书写入、MVU 解析失败、部分任务失败 | 返回型无写副作用；写入失败不报成功；逐任务结果可定位；事件成功提交不被同组失败回滚 |
| A8 | 两运行修改同一目标；替换条件已变化；常规链回滚 | 基于最新内容提交或明确冲突；不同目标的事件结果保留；重叠警告与风险表达符合契约；无旧快照静默覆盖 |
| A9 | 旧配置、重载、配置与预设导出 | 旧格式明确不支持；新配置持久化正确；密钥不在普通配置/脚本变量/导出中；清理不影响其他模块数据 |
| A10 | 检查所有生产生成与配置入口 | Profile、全局预设切换、共享过滤状态、旧生成入口与迁移链已退出；旧正文配置字段和 UI 不再读写或生效，旧过滤监听不再注册；任务候选池仍按任务配置工作 |

验证分层：

- 确定性行为与契约验证：扫描、预设原生字段保留、任务调度、结果和提交/回滚。唯一权威入口为 `tests/async-tasks/` 的 generation、commit、runtime、configuration 四个 suite；不把旧 EraDataRule 样例作为基础。
- 宿主集成验证：实际原版酒馆、酒馆助手、提示词模板及 MVU 环境中的调用、EJS 和并发边界。可用可控端点/请求观测保证交错场景可重现；记录宿主与扩展版本。
- 构建与静态检查：使用仓库现有 pnpm build:dev / build 与必要的定向静态检查，不能替代上述行为证据。不为形式运行全仓库无关检查。
- 稳定测试资产只有一个权威位置；独立验收可复用实现自测资产，补真实缺口，临时观测代码收口时删除或明确纳入长期宿主门禁。
- 宿主环境不可用时，完成能独立验证的部分并明确记录缺口，状态停留在待验收，不能宣称全部完成。

## 旧机制取缔项（已获用户破坏性更新授权）

- 退出任务生成的 Profile、Sample/External 多源分支及跟随全局当前预设/连接的机制，统一为显式连接配置与插件预设副本。
- 退出任务全局 loadPreset、/profile 切换、originalGlobalPreset / restoreGlobalPreset 及相应恢复生命周期。
- 退出 PromptUtil 中旧 generate 生成职责，以及只为旧调用保留的 wrapper、字段映射和中间表示。
- 退出旧正文世界书过滤机制：规则组正文 world_book 配置、对应 UI 和持久化读写、WORLDINFO_ENTRIES_LOADED 过滤监听、共享黑白名单及恢复逻辑。任务候选池直接消费任务配置，不复用这些旧职责。
- 退出过滤锁、全局生成锁、固定启动延迟，以及依赖主聊天发送前事件和计时窗口的正确性机制，不拆出正文过滤模块或 wrapper 延续旧路径。
- 退出以单一 isAnalyzing / currentAnalysisRunId / savedBackupState 同时控制无关运行的机制，删除事件静默跳过路径。
- 退出对未执行任务做备份、跨运行复用单份备份，以及无法保留独立提交的整消息/整条目盲目恢复。
- 退出旧 staged_setting 迁移、旧配置兼容、重复采样字段、旧 API/事件别名和失去职责的转换器；旧 VariableInsert/Edit/Delete 兼容转换退出，保留仍被当前 MVU 契约需要的写入能力。
- 退出脚本变量中的连接密钥读写及含密钥配置导出；只为这些旧路径存在的 UI、类型、日志、测试与文档同步移除或改写。

清理只依据真实职责和依赖，不因文件历史命名删除仍在服务 MVU 编辑或版本更新的代码。旧正文配置和过滤已明确取缔，不作为保留旧代码的理由。允许真实宿主边界 adapter，不保留无业务职责的内部兼容壳。
