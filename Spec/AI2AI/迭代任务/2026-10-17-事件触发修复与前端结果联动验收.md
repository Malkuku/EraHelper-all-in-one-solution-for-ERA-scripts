| 风险 | 验收入口与判断 |
| --- | --- |
| 关闭常规参与导致事件也无法执行 | 生产注册的 sent/received 与 KatTaskAPI 常规入口按 enabled 筛选；带事件名且 enabled 的任务仍参与常规。关闭常规参与的任务仍可被事件执行。 |
| 测试仅能执行常规链 | KatTaskAPI 指定 taskId，只执行目标；负 order 可显式执行；事件任务保留事件频道；未关联、缺失及事件不匹配 ID 明确失败。 |

| UI 可选入口与实际执行脱节 | 生产 App fixture 检查常规/事件/单任务选择、写入提示、禁用和规则复制，区分模拟宿主与真实酒馆。 |
