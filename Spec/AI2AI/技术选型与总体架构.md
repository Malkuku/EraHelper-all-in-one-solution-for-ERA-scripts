# 技术选型与总体架构

## 运行模型

仓库使用 pnpm、TypeScript、Webpack、Vue 3、Pinia 与 Vue Router。Webpack 扫描 src/**/index.ts；`src/MVU助手/index.ts` 导入 UI 和按钮，作为酒馆助手脚本运行。宿主变量、消息、世界书及 MVU API 是运行前提。pnpm 11 的依赖构建许可由根 `pnpm-workspace.yaml` 的 allowBuilds 管理，不使用已失效的 package.json.pnpm 配置；包版本和锁文件未因此变更。

## 生成与提交数据流

1. 初始化读取 TaskStore 与 UI 偏好，注册 TaskRuntime 的消息、自定义事件、重算和取消入口。没有正文世界书过滤监听器。
2. 每次运行复制配置并绑定聊天/消息/swipe 身份；每个任务自行读取候选池和历史。组间有序，组内请求并发；事件与常规链互不作废。
3. 任务候选副本强制启用后执行完整原生扫描语义。任务只选择 API 配置，API 的 presetId 决定预设，预设 raw 是提示词与采样的权威来源；API 同时负责地址、模型和密钥引用。角色卡、玩家人设和作者注释不自动发送，保留显式宏/模板读取。

   任务正则页提供 `useTavernRegex` 勾选项，默认关闭。启用时由 `GenerationHost` 对正文历史调用酒馆助手 `formatAsTavernRegexedString`，复用酒馆当前全局、预设和局部正则的提示词筛选，传入消息来源及实际聊天深度；正则取自酒馆当前预设，随后再执行显式 history 正则。生成请求与世界书扫描消费同一处理结果，聊天原文、任务提示词、世界书内容和模型响应不受此开关改写；不复制宿主规则列表。
4. EJS 由本任务调度预处理、GENERATE 前后与注入阶段，getpreset 指向任务预设，自动特殊条目限定候选池，显式 getwi 可读池外。GENERATE:AFTER 仍在 HTTP 之前，不是模型响应后回调。`TaskMacros.ts` 统一处理原生宏与助手内置变量宏（get/format/format_quoted，五种宿主变量作用域），供模板和世界书扫描共用；消息变量默认使用当前聊天最后一个具有变量的楼层及其当前 swipe，不广播全局生成事件。自定义 registerMacroLike 宏不在本地兼容范围。
5. 插件通过父页同源 Chat Completions 后端发独立文本请求，显式覆盖本次连接凭据；不调用 Generate/generate，不切全局预设/连接，不模拟广播全局生成事件。
6. 纯返回任务只交付文本。写入任务在短目标锁中读取最新内容、先完成 MVU 纯解析，再提交正文/世界书/MVU。成功历史和时序仅在任务成功后推进。
7. 事件任务独立结算；常规链按实际提交序列逆序补偿，不能按模型完成或 state ack 顺序恢复。目标重叠警告继续；不能证明片段/路径归属时报告冲突并保留剩余 Journal。

## 任务配置界面约束

事件开关与间隔以原版规则为准：enabled仅控制常规链，事件匹配忽略enabled；间隔1不限制重复，间隔>1从0或上次触发基线计算，包含事件。楼层回退跳过并重置triggerBaseline，独立于成功历史。运行页提供常规链、指定事件和单任务真实测试；taskId测试跳过间隔且不替代最近常规链日志。事件结果广播模式通过既有事件名:result的tasks[].text交付，不持久化结果，不新增频道。可复制的联动规则由EventIntegrationRules.ts维护。配置字段说明支持hover、焦点和点击。

工作台明确分离导航、配置内容和操作；不在每页顶部常驻全部生效组合、步骤清单、变更统计和配置工具。必要的保存状态保持清楚，生效配置在规则组/运行上下文查看，帮助和导入导出按需打开。API 页绑定预设，任务不再独立选择预设；引用任务为独立的可展开列表，不与清密钥或删除动作混排。连接测试和获取模型列表沿用原版 GET /models，使用当前草稿地址、密钥（空输入保留本地、显式清空使用空值），不要求先保存；显示数量与模型选择，提供失败重试及取消。该检查只证明模型列表接口可用，不宣称生成已验证。过期请求不能覆盖当前连接结果。

2026-10-17 用户明确授权依据玩家与产品设计审阅直接重构 UI。当前采用完整工作空间：顶栏提供产品名、主题与关闭，一级导航为任务工作台、变量编辑、数据更新和关于；任务、规则组、API、预设、正则、运行记录与通用设置在工作台内组织。窗口受实际父页可视范围约束，按内容容器宽度切换分栏，低高度不得裁切导航或关闭入口。共享 `UI/design.scss` 管理语义颜色与控件，深浅主题共用同一状态含义。

Layout 使用 `v-show` 和路由 `KeepAlive` 保留当前脚本会话内的页面及草稿，关闭、切换主功能不会静默放弃配置或变量修改；脚本重载不承诺草稿恢复，草稿密钥不新增存储渠道。普通配置仍整份保存，但保存只验证JSON形状、稳定ID等数据结构，允许名称、地址、模型、绑定、正则和原生预设语义未完成；不要求所有资源可运行，不以占位假值绕过校验。JSON损坏等结构错误能定位到对应对象。运行使用已保存配置，由`TaskConfiguration.validateTaskReadiness`在所选任务准备阶段核验实际依赖，缺项不发请求，闲置未完成资源不阻拦正常任务。现行常规链停止/回滚与事件独立结算语义不变。

工作台功能按“配置（预设/API）、编排（任务/规则组）、运行、工具”组织，预设与API在前；规则组选择和管理收敛为单一入口。宽空间采用分组功能导航，窄空间使用明确功能选择，避免多排标签和按钮混杂。列表/详情用于配置对象，任务列表紧凑呈现，API表单按连接、密钥、检测与引用关系分区。

资源删除的唯一语义在`TaskConfiguration.removeTaskResource`：删除API仅清空任务connectionId，删除预设仅清空API presetId，任务/API/组本身保留；删除任务解除组引用，删除活动组清空活动选择。引用关系不阻拦删除，也不自动删除消费者；这些操作先修改草稿，保存后生效。结构仍为schemaVersion 2，空任务绑定使用空字符串，空预设绑定使用null；支持可编辑未完成状态属于兼容扩展。

运行记录第一层展示数据影响，回滚失败/残留修改必须直接可见；任务错误和写入目标不藏入技术诊断。手工运行说明使用已保存配置与本次目标；重算明确先撤销会话中上条常规链，日志可用性由任务内核校验。清空显示记录不会撤销写入或清理任务状态。`utils/useDialogFocus.ts` 是模态层焦点、背景 inert 与宿主滚动锁的共享责任层，按挂载元素的 ownerDocument 管理，支持嵌套和关闭后的焦点恢复。

运行结果页以阅读记录为主：手动运行/测试默认收起，摘要保留当前楼层、规则组及未保存草稿提示；展开后提供运行范围、实际影响及执行动作，运行规则和前端联动另行按需展开。每条记录常驻状态、来源、楼层、任务状态统计、数据影响、具体任务失败原因和写入目标；残留修改与回滚错误不受折叠影响。最新记录默认展开任务明细，历史明细默认收起；返回全文、技术详情（API/模型/地址/耗时/后端响应）、运行提醒与标识诊断默认收起。此规则替代此前失败响应和单任务返回全文默认展开的展示方式，完整信息与复制诊断仍保留。

任务通知由 App 常驻的 `TaskNotifications.vue` 展示，使用 ownerDocument 的浏览器顶层 popover，独立于助手工作窗口开关。默认收起为一行状态条，点击或键盘展开后查看详情、取消操作和日志，可随时再次收起；结果返回只原位更新状态，不强制展开或打断当前阅读。按 runId 原位更新处理中和终态，处理中不超时、不提供关闭；完成后保持显示至手动关闭。自动跳过/忙碌仍静默，显式操作有反馈；不再由 toastr 承担任务开始/结算通知。

`TaskDiagnostics.ts` 是过程日志权威来源，脱敏后保留当前脚本会话的每次运行日志，同时输出控制台，不受控制台日志等级过滤影响。通知及运行记录共用 `RunLog.vue`，直接展开阶段、重试、请求、后端原始响应、原始输出与提交/回滚日志，复制诊断包含这些日志。未取得响应时说明已执行的阶段，不要求用户转到控制台。日志不写入脚本变量或 localStorage，重载无法恢复既往日志。

世界书配置通过酒馆助手读取真实书单与条目，提供搜索、选择和 UID 对应，不要求用户手填内部标识。读取失败应显示原因并允许重试，不能清空已有选择。任务候选与写入目标均需支持该操作。

世界书条目恢复原版的已选名称标签与展开选择交互：收起列表或搜索时仍显示全部已选名称，可逐项移除；列表高亮勾选项，内容预览不改变选择。界面不展示 UID，内部仍按稳定标识维护选择。读取失败保留选择并提示未读状态。字段提示图标与标题同排，不能独占一行；共享浮层使用 ownerDocument 顶层 popover，定位完成前保持隐藏，浮层样式使用专属类名，支持跨文档挂载及窄屏边界约束。

正则库与测试器是保留的产品能力：支持保存、复用、导入导出和实际运行语义的预览。旧任务配置不迁移，不代表可以删除用户已有正则库；旧 `saved_regex_configs` 数据保留并提供显式导入入口。界面编辑统一使用当前 TaskSettings 草稿，切页保留编辑，外部更新不得静默覆盖未保存内容。

## 表单视觉责任层

`UI/design.scss` 统一定义原生输入框、文本域和选择框的编辑底色、边框及聚焦反馈；浅色与深色主题均须在未聚焦时可辨认编辑边界，输入内容使用常规字重，不继承字段标签的加粗。只读和禁用态与可编辑态区分，复选框、单选框和文件输入不套用文本编辑底色。任务配置组件复用该责任层，保留宽度与排列等布局样式。任务工作台按页面标题、字段标签、编辑内容、辅助说明区分层级，关联任务中的名称优先于触发参数和资源信息。

## 持久化与生命周期

普通配置仅有脚本变量 `async_task_config`；密钥在同源 localStorage 的本模块命名空间中。聊天变量保存本脚本 task 的成功历史与时序状态，不写宿主 timedWorldInfo。准入序列从持久化高水位继续，避免重载后同楼新运行被旧序号压制。

Journal、最后可重算链、在途运行和补偿失败诊断属于当前脚本会话。重载后不声称可以恢复旧 Journal；专用重算在已成功楼层没有日志时明确失败。旧结果为发布时的终态快照，剩余 Journal 只通过只读诊断 API 查询，不建立第二套业务结果。

任务提交不使用 MvuUtil 的 last-message helper；它调用绑定楼层的 MVU 接口。MvuUtil 仍服务无关的变量编辑、版本更新和滑动消息行为，这些模块未被此次生成重构替代。

## 宿主边界与验证状态

详细支持范围、字段映射、固定源码基线和风险见 [分步任务契约](./API/分步任务目标契约.md)。`SillyTavern.getContext()` 来自父页面，原生 loadWorldInfo 在父 realm 调用并复制返回值，不从脚本 iframe import 宿主主模块以免重载模块图。

本地确定性测试覆盖并发载荷、扫描、模板 adapter、运行、配置与补偿；它们不证明真实 EJS、部署鉴权、主聊天与任务同时运行、MVU 持久化或预设回到酒馆的往返。实际宿主版本仍须独立验收，不把调查版本宣传为最低支持版本。

扫描器保留固定 SillyTavern AGPL-3.0 代码及相邻完整许可文本。仓库根 AFPL 未变，本轮未分发；对外分发前需确认许可组合，不推断二者兼容。
