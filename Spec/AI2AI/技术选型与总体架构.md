# 技术选型与总体架构

## 运行模型

仓库使用 pnpm、TypeScript、Webpack、Vue 3、Pinia 与 Vue Router。Webpack 扫描 src/**/index.ts；`src/MVU助手/index.ts` 导入 UI 和按钮，作为酒馆助手脚本运行。宿主变量、消息、世界书及 MVU API 是运行前提。pnpm 11 的依赖构建许可由根 `pnpm-workspace.yaml` 的 allowBuilds 管理，不使用已失效的 package.json.pnpm 配置；包版本和锁文件未因此变更。

## 生成与提交数据流

1. 初始化读取 TaskStore 与 UI 偏好，注册 TaskRuntime 的消息、自定义事件、重算和取消入口。没有正文世界书过滤监听器。
2. 每次运行复制配置并绑定聊天/消息/swipe 身份；每个任务自行读取候选池和历史。组间有序，组内请求并发；事件与常规链互不作废。
3. 任务候选副本强制启用后执行完整原生扫描语义。预设 raw 是提示词与采样的权威来源；连接是地址、模型和密钥引用的权威来源。角色卡、玩家人设和作者注释不自动发送，保留显式宏/模板读取。
4. EJS 由本任务调度预处理、GENERATE 前后与注入阶段，getpreset 指向任务预设，自动特殊条目限定候选池，显式 getwi 可读池外。GENERATE:AFTER 仍在 HTTP 之前，不是模型响应后回调。
5. 插件通过父页同源 Chat Completions 后端发独立文本请求，显式覆盖本次连接凭据；不调用 Generate/generate，不切全局预设/连接，不模拟广播全局生成事件。
6. 纯返回任务只交付文本。写入任务在短目标锁中读取最新内容、先完成 MVU 纯解析，再提交正文/世界书/MVU。成功历史和时序仅在任务成功后推进。
7. 事件任务独立结算；常规链按实际提交序列逆序补偿，不能按模型完成或 state ack 顺序恢复。目标重叠警告继续；不能证明片段/路径归属时报告冲突并保留剩余 Journal。

## 任务配置界面约束

任务内核重构不构成重设计界面或删除操作能力的授权。任务管理沿用原版的顶部导航、规则卡片、搜索列表和分栏编辑方式；任务基础配置、世界书候选、正则与结果处理分区呈现。新内核的预设管理、运行结果与取消也须有明确入口。

世界书配置通过酒馆助手读取真实书单与条目，提供搜索、选择和 UID 对应，不要求用户手填内部标识。读取失败应显示原因并允许重试，不能清空已有选择。任务候选与写入目标均需支持该操作。

正则库与测试器是保留的产品能力：支持保存、复用、导入导出和实际运行语义的预览。旧任务配置不迁移，不代表可以删除用户已有正则库；旧 `saved_regex_configs` 数据保留并提供显式导入入口。界面编辑统一使用当前 TaskSettings 草稿，切页保留编辑，外部更新不得静默覆盖未保存内容。

## 持久化与生命周期

普通配置仅有脚本变量 `async_task_config`；密钥在同源 localStorage 的本模块命名空间中。聊天变量保存本脚本 task 的成功历史与时序状态，不写宿主 timedWorldInfo。准入序列从持久化高水位继续，避免重载后同楼新运行被旧序号压制。

Journal、最后可重算链、在途运行和补偿失败诊断属于当前脚本会话。重载后不声称可以恢复旧 Journal；专用重算在已成功楼层没有日志时明确失败。旧结果为发布时的终态快照，剩余 Journal 只通过只读诊断 API 查询，不建立第二套业务结果。

任务提交不使用 MvuUtil 的 last-message helper；它调用绑定楼层的 MVU 接口。MvuUtil 仍服务无关的变量编辑、版本更新和滑动消息行为，这些模块未被此次生成重构替代。

## 宿主边界与验证状态

详细支持范围、字段映射、固定源码基线和风险见 [分步任务契约](./API/分步任务目标契约.md)。`SillyTavern.getContext()` 来自父页面，原生 loadWorldInfo 在父 realm 调用并复制返回值，不从脚本 iframe import 宿主主模块以免重载模块图。

本地确定性测试覆盖并发载荷、扫描、模板 adapter、运行、配置与补偿；它们不证明真实 EJS、部署鉴权、主聊天与任务同时运行、MVU 持久化或预设回到酒馆的往返。实际宿主版本仍须独立验收，不把调查版本宣传为最低支持版本。

扫描器保留固定 SillyTavern AGPL-3.0 代码及相邻完整许可文本。仓库根 AFPL 未变，本轮未分发；对外分发前需确认许可组合，不推断二者兼容。
