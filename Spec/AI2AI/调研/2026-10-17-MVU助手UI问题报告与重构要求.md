# MVU 助手 UI 问题报告与高标准重构要求

日期：2026-10-17。状态：双视角审阅已交付；本文件保留实施前问题快照。用户已授权直接实施，当前进度及最终证据见 [UI高标准重构](../迭代任务/2026-10-17-MVU助手UI高标准重构.md)，不以本报告判断修改后的界面仍有相同问题。

## 判断

当前界面具有任务、API、预设、世界书和正则等必要能力，但尚未达到高标准玩家工具的要求。主要问题是数据操作缺少目标上下文、草稿生命周期不一致、完整窗口布局存在裁切，以及复杂配置缺少清晰的操作路径。重构不能仅更换颜色、圆角或阴影，应同时重建窗口布局、导航、编辑状态、运行反馈和数据写入交互。

审阅由两个独立子 Agent 完成：[玩家审阅](./2026-10-17-MVU助手UI玩家审阅.md)、[产品设计审阅](./2026-10-17-MVU助手UI产品设计审阅.md)。root 负责交叉核对关键代码、补充完整外壳浏览器证据和形成本报告。角色审阅属于专家走查，不代表真实玩家访谈或用户测试。

## 目标界面结构

建议保留现有能力和任务内核，将导航围绕玩家工作组织。以下为设计建议，不自动取代现行架构契约。

| 层次 | 内容 | 关键交互 |
| --- | --- | --- |
| 应用顶栏 | MVU 助手、当前聊天/楼层、主题、关闭 | 顶栏占据正常布局位置，工具不悬浮覆盖正文 |
| 一级导航 | 任务工作台、变量编辑、版本更新；版本信息放辅助入口 | 当前页明确，离开编辑页时保护草稿 |
| 任务工作台 | 任务、规则组、API连接、预设、正则库、运行记录 | 每类对象一个清晰入口；必要时由任务跳至依赖对象并返回原上下文 |
| 任务详情 | 基础/触发、输入/世界书、输出/正则、高级设置 | 先显示常用项；实时摘要解释实际触发与写入对象；高级扫描参数渐进展开 |
| 保存区 | 当前草稿状态、错误摘要、保存、放弃 | 长表单滚动后仍可达；导入/导出等次要操作与主提交区分 |
| 运行记录 | 运行摘要、数据影响、任务结果、诊断 | 优先回答是否改数据、是否撤销、下一步；技术ID放诊断层 |
| 变量与更新 | 目标身份、草稿/预览基线、变更对照、提交 | 提交读取同一目标；过期快照不可继续覆盖 |

配置引导保留“预设 → API绑定预设 → 任务选择API → 组关联 → 保存启用”的现行关系。空配置时完整引导，完成后收起为配置完整性摘要；不在每个页面重复五步按钮。列表支持搜索、选中态和空状态；手机采用列表/详情分屏切换，保留返回时的搜索与滚动位置。

## 设计系统与验收门槛

以下数字是本报告提出的设计目标，实施时应写入任务验收要求；它们不构成新的业务规则。

- 采用统一颜色、间距、字体、边框、层级和状态 token；统一按钮、字段、错误、列表、状态条、对话框，不再由每页各自定义一套。
- 正文默认14–16px；辅助信息通常不低于12px；手机主要触控区域以44×44px为目标。不得通过缩放文字解决布局问题。
- 以正文对比4.5:1、大字及必要控件边界3:1作为拟定验收值；实现阶段实际测量，不凭截图宣称符合无障碍标准。
- 使用布局流处理顶栏与操作栏；按可用容器尺寸切换布局，避免固定最小高度超过宿主。脚本当前挂载/传送父页样式的边界需与消息iframe界面规则区分，重构前明确实际承载容器。
- 普通编辑页优先一个主要纵向滚动区；弹窗明确自己的滚动与焦点范围；不出现必须滚动到另一个容器才能找到保存按钮的陷阱。
- 所有异步操作都有加载、成功、失败、取消/重试和过期响应状态；保留当前已实现的模型接口检查、世界书读取失败保留选择、迟到响应隔离能力。
- 危险操作说明具体对象和影响；普通安全操作保持直接。清空记录、重算、写入变量分别命名，不能共用模糊“确定”。
- 键盘能完成导航、选择、编辑、保存、取消和恢复；焦点清晰，弹窗打开和关闭不丢焦点；降低动态效果偏好受到尊重。

## 验收场景

1. 首次使用：从空配置导入预设、绑定API、读取模型、创建任务、选世界书、配置输出、关联组并保存。每一步能在界面内判断下一步与错误原因。
2. 草稿：内部tab、跨一级路由、关闭重开、刷新、导入、外部配置变化；每条路径有一致且可观察的结果，raw JSON导出与保存一致。
3. 数据目标：编辑/预览后追加楼层、切聊天、切swipe、任务更新同一数据；旧草稿不能误写新对象，比较与重新加载可用。
4. 运行结果：成功、无写入失败、取消、部分完成、回滚完成、回滚失败、无会话日志的重算；页面直接说明数据状态与下一步。
5. 依赖失败：模型接口拒绝/超时、世界书读取失败、正则无效、版本块损坏、保存失败；保留输入，错误定位清楚，可重试，迟到响应不覆盖新状态。
6. 完整窗口：1440×900、1366×768、1024×600、768×600、375×812及200%缩放；覆盖列表、长任务、弹窗、长名称、空数据与错误页。没有横向溢出，也没有纵向裁切、不可达按钮或焦点陷阱。
7. 真实酒馆：明暗主题、父页样式、关闭重开、消息到达与聊天切换、真实世界书/MVU集成；手机软键盘和低高度场景单独检查。

已有确定性回归继续复用 `tests/async-tasks/`；新增测试按实际责任扩展，不能新建一套重复业务真值。视觉与交互验收必须挂载实际完整窗口；构建、lint、组件截图均不能单独作为最终通过证明。
