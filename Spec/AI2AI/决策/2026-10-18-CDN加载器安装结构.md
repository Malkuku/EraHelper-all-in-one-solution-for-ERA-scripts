# CDN 加载器安装结构

## 已确定的决定

2026-10-18 用户选择：酒馆助手脚本中长期保留一个小加载器，核心代码通过 CDN 加载选定版本。

- 加载器是长期安装入口，核心业务代码作为独立版本产物发布。
- 后续核心版本更新通过加载器选择、加载对应版本完成。
- 延续维护者手动正式发布、日常提交不向玩家发布的既有决定。
- 正式核心产物存放在 GitHub 仓库的 `releases/mvu/{version}/` 目录中，通过目录名称标记版本，由jsDelivr分发。

## 当前实现状态

用户已确认GitHub版本目录、jsDelivr固定提交核心与可刷新公告的方向，当前进入[实现迭代](../迭代任务/2026-10-18-CDN加载器与版本发布.md)。具体行为以[CDN加载与更新契约](../API/CDN加载与更新契约.md)为准。

正式产物与公告尚未发布，实际jsDelivr和真实酒馆集成仍待验证。官方清缓存工具需要验证码，加载器提供官方页面入口与公告地址，刷新后重新检查实际读到的版本，不承诺立即生效。
